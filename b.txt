Claude Code 대화 내용 백업
프로젝트 개요
프로젝트명: 한국 커뮤니티 애그리게이터 웹 앱
목적: 디시인사이드, 루리웹, 아카라이브의 게시글을 한 곳에서 모아보기
환경: CLI Claude Code에서 시작 → 웹 Claude Code로 전환 예정 (프로모션 크레딧 사용)
완료된 작업
1. 프론트엔드 개발 (완료 ✅)
기술 스택:

React + TypeScript + Vite
Tailwind CSS v4
Mock 데이터 (JSON)
구현된 기능:

여러 커뮤니티의 게시글을 카드 형식으로 표시
커뮤니티별 필터링 (전체/디씨/루리웹/아카 탭)
검색 기능 (제목/내용)
게시글 클릭 시 상세 보기 모달
프로젝트 구조:

src/
├── components/
│   ├── common/
│   │   ├── Header.tsx       # 헤더 + 검색바
│   │   ├── PostCard.tsx     # 게시글 카드
│   │   └── PostModal.tsx    # 상세보기 모달
│   └── PostList.tsx         # 목록 + 필터
├── data/
│   └── mock-posts.json      # Mock 데이터 10개
├── types/
│   └── index.ts             # TypeScript 타입
└── App.tsx
주요 이슈 해결:

Tailwind CSS v4 설정 문제 해결
@import "tailwindcss" 방식으로 변경
tailwind.config.js 삭제 (v4에서 불필요)
실행 방법:

npm install
npm run dev
2. 크롤러 개발 (구조 완성 ✅, 실제 작동 ⚠️)
기술 스택:

Node.js + TypeScript
Axios (HTTP 요청)
Cheerio (HTML 파싱)
node-cron (스케줄링)
프로젝트 구조:

crawler/
├── src/
│   ├── crawlers/
│   │   ├── base.ts          # 기본 크롤러 클래스
│   │   ├── ruliweb.ts       # 루리웹 크롤러
│   │   ├── arcalive.ts      # 아카라이브 크롤러
│   │   └── dcinside.ts      # 디시인사이드 (비활성화)
│   ├── utils/
│   │   ├── fetcher.ts       # HTTP 요청 + 재시도 로직
│   │   └── logger.ts        # 로깅
│   ├── config.ts            # 설정
│   ├── types.ts             # 타입 정의
│   ├── index.ts             # 메인 (스케줄러)
│   └── test.ts              # 테스트 스크립트
├── package.json
└── tsconfig.json
안전 장치 구현:

요청 간 3초 딜레이 (서버 부하 최소화)
재시도 로직 (exponential backoff)
게시판당 최대 20개만 수집
상세 내용은 가져오지 않음 (제목, 작성자, 통계만)
robots.txt 준수 (디시인사이드 비활성화)
크롤링 전략:

✅ 루리웹: robots.txt 관대함 → 실제 크롤링 구현
✅ 아카라이브: robots.txt 관대함 → 실제 크롤링 구현
⚠️ 디시인사이드: robots.txt 제한 → 구조만 작성, 실제 크롤링 X
실행 방법:

cd crawler
npm install
npm test        # 한 번만 실행 (테스트)
npm start       # 스케줄러 포함 (30분마다)
출력:

src/data/posts.json (프론트엔드에서 바로 사용 가능)
